# 50 Email Security and Phishing Assessment Projects

A hands-on, authorized training collection covering email infrastructure, authentication, phishing awareness, detection engineering, identity protection, and incident response.

**Status:** In progress — project files will be added in the next commits.

## Safety and authorization

All exercises are designed for isolated labs, synthetic identities, test mailboxes, benign sample data, and systems you own or are explicitly authorized to assess. Do not send simulations to real users without written approval. Never collect real passwords, session cookies, or authentication tokens. Evilginx-related material is limited to defensive architecture analysis, telemetry, detection, and mitigations; no credential or session capture, MFA bypass, or real-world targeting.

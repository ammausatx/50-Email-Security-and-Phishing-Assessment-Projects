# 50 Email Security and Phishing Assessment Projects

A hands-on portfolio covering email infrastructure, authentication, phishing awareness, gateway configuration, detection engineering, identity protection, and incident response.

## Safety and authorization

All exercises are designed for isolated labs, synthetic identities, test mailboxes, harmless samples, and systems you own or are explicitly authorized to assess. GoPhish projects use dummy recipients, local SMTP sinks, benign landing pages, and no credential collection. Evilginx-related projects are strictly defensive: threat modeling, synthetic telemetry, detection, and mitigation only. No credential or session-token harvesting, MFA bypass, interception deployment, or targeting real users/services.

- Beginner: Projects 01–15

## Standard deliverables

Each project includes an objective, authorization boundaries, prerequisites, lab setup, repeatable walkthrough, example commands or tools, expected output, risk assessment, framework mapping where relevant, remediation, validation criteria, evidence checklist, and three project-specific simulated SVG training illustrations.

## Lab safety

Use fictional `.test` domains, reserved example addresses, sanitized logs, and disposable synthetic identities. Keep lab mail routing isolated. Never collect real credentials, tokens, cookies, or sensitive personal information. Do not run tests against systems outside written scope.
